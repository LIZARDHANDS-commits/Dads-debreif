LIVE TRAFFIC is now provider-native.

The main screen embeds the Airplanes.live globe itself, preserving its own map controls, aircraft selections, filters, labels and other website functions instead of recreating them through our API renderer.

The Netlify traffic function tries ADSB.lol first and automatically falls back to Airplanes.live. It requests aircraft within 100 NM of CYMJ and refreshes every 10 seconds.

The active provider is shown on the MAIN MAP sidebar.

Weather: AviationWeather.gov METAR/TAF + RainViewer radar, both proxied through Netlify. Airport weather and radar are independent layers so a radar failure will not remove METAR information.
Important: Traffic and weather layers are situational-awareness aids only and are not ATC surveillance or approved operational weather sources.
