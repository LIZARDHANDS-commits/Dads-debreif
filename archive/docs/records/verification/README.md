# Verification reports

These are the independent checker's reports from 30 Sep 2026, copied from the project files. Start with [FRICTION.md](FRICTION.md), a one-page summary of where work went wrong and what to simplify.

- [index.md](index.md) is the running index the checker kept, one line per check.
- Each report is named `<module>-<what>.md`. The first-pass reports are named by module alone.
- The final end-of-module checks are [debrief-final.md](debrief-final.md), [sof-final.md](sof-final.md) and SOF's own [sof-end-of-module.md](sof-end-of-module.md).

Screenshots and weather fixtures are not copied, to keep the repo small. Paths like `/mnt/project-files/verification/shots/...` in the reports point to the project files, not to this repo. Manual text is paraphrased with its page or figure reference, not quoted.
